gadget-roast is a tiny program that writes one roast line about a gadget you use every day to a file: a smartwatch that throws a party every time its wearer stands up, then watches in silence while the wearer eats an entire pizza sitting down.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run.
