gadget-roast is a tiny program that writes a single roast line about an everyday gadget to a file. The gadget here is a smartwatch: it throws a party every time its wearer stands up, then watches in silence while the wearer eats an entire pizza sitting down.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access is needed, and every run writes the same text, byte for byte. The program checks the line first — one line, 1 to 200 characters, ending with a period — and reads the file back to confirm it matches.
